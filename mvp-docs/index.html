How to read this set

This is the canonical documentation set for the Amaea compliance platform MVP. Five documents cover different aspects of the product — each readable on its own. Read in order if you're new to the project, or jump straight to whichever doc matches your role.

Document conventions

  • Code paths are absolute or relative to /Users/milan/Documents/Amaea/.
  • All references to FCA rules use the FCA Handbook abbreviation pattern: COBS 9.5, PS22/9, FG21/1, SYSC 9.1, DISP 1.6.1.
  • "We" in operational docs refers to Sterling IFA (the demo firm) where the context is product behaviour, or to Amaea (the firm) where the context is business decisions.
  • Money values shown in pounds sterling.
  • Dates in ISO 8601 (YYYY-MM-DD) or "DD Month YYYY" UK format.
