What Amaea is

Amaea is an FCA compliance platform for UK Independent Financial Adviser (IFA) firms. It replaces manual compliance tracking — spreadsheets, fragmented file checking, and reactive supervision — with a single AI-driven dashboard that monitors every client's compliance state in real time.

The product reads the documents IFAs already produce — Fact Finds, Suitability Reports, Annual Reviews, Pension Transfer Reports, Letters of Authority, AML records — extracts the compliance-critical fields from each one using Claude vision, validates them against the FCA Handbook, and raises specific compliance flags with rule citations when something is missing or wrong.

The headline value: an IFA firm using Amaea can answer questions like "Which clients have unsigned suitability reports?" or "Which DB transfers are missing cooling-off notices?" or "What's our Consumer Duty position right now?" in seconds, with evidence linked to the source document. Without Amaea, those answers require manual file review.

Who it's for

The MVP target is UK IFA firms with 5–15 advisers — large enough to have a compliance burden the founders genuinely feel (annual reviews, RMAR, Consumer Duty board assessments) but small enough that they don't already have a dedicated compliance team using enterprise tools.

The post-MVP expansion target is the full UK regulated services market — mortgage brokers, insurance intermediaries, wealth managers, accountants — all of whom face similar documentation and supervisory obligations under different FCA / PRA / ICAEW rulebooks.

The long-term target is the global compliance intelligence layer — but everything before 2030 is focused on owning UK IFA.

Why now

Three forces have aligned in 2024–2026 to make this product possible and commercially attractive:

  1. Consumer Duty (PS22/9, in force from July 2023) has materially increased the documentation burden on IFAs. Firms now need to evidence good outcomes across four outcome areas for every client, every year, plus an annual board assessment. The manual cost of doing this well is significant.
  2. AI vision models can now read the documents IFAs produce (mostly PDFs and phone-photographed scans) to a standard that genuinely competes with a junior compliance officer. Claude Sonnet 4.6's vision performance on real IFA documents — Fact Finds with mixed handwriting and form layouts, multi-part Suitability Reports of 40+ pages, hand-completed AML/CDD records — is what unlocks this product. The pipeline pulls structured compliance fields out of these documents at >85% extraction accuracy on the test corpus.
  3. The FCA has been data-led in supervision since 2022. Firms that look bad on regulatory data (overdue reviews, complaints data inconsistencies, missing documentation patterns) are identifiable before a supervision visit even takes place. Amaea is in effect a "look as good as you should" tool for firms that ARE compliant but can't easily prove it.

Key features (MVP)

1. Document import with 19-type extraction

Drag and drop any IFA compliance document. The system classifies it as one of 19 canonical types (Suitability Report, Fact Find, Client Agreement, Annual Review, DB Transfer Report, Vulnerability Assessment, Consumer Duty Outcome, Letter of Authority, Product Illustration, Terms of Business, Complaint Record, Ongoing Service Evidence, AML/CDD, Training & Competency, Expression of Wish, Application Form, Portfolio Snapshot, Sales File Cover, Attitude to Risk), extracts the compliance-critical fields per the document type, validates against a strict Zod schema, and persists to the database.

Multi-part documents (a 5-part Suitability Report, an 18-page ATR questionnaire) can be uploaded as a group via a single toggle — the system treats them as one consolidated document and extracts across all pages.

Full detail: see 03 — Document Extraction & Compliance Flag System.

2. Auto-flag-raising with FCA rule citations

When the extraction completes, the system runs the result through a flag-raising function that checks for compliance gaps and raises specific flags with the FCA rule that's been breached. Examples:

  • DB Transfer Report with coolingOffNoticeProvided = false → critical cobs_19_breach flag citing COBS 19.1
  • Fact Find with attitudeToRiskRating = null → high incomplete_kyc flag citing COBS 9.2
  • Letter of Authority with authorityExpiryDate < today → medium expired_loa flag citing COBS 2.1
  • Complaint Record with acknowledgedDate - complaintReceivedDate > 5 days → high disp_breach flag citing DISP 1.6.1
  • AML/CDD with cddLastRefreshedDate > 3 years ago → high aml_cdd_stale citing SYSC 6.3 / MLR 2017

Every flag is linked back to the source document and the source FCA rule. This is the audit-trail spine of the product.

3. AI compliance assistant

A chat interface on the dashboard and /assistant page. Asks questions and gets answers grounded in two retrieval sources: the firm's own live data (clients, reviews, flags, recent uploads) and an 11,645-chunk knowledge base of FCA regulatory text (full Handbook + Final Notices + Dear CEO letters + Policy Statements + Thematic Reviews).

The chat correctly distinguishes between things it can assert specifically (because there's evidence in an uploaded document) and things it can only summarise (because the underlying file hasn't been seen). It doesn't hallucinate rule citations.

Full detail: see 04 — AI Layer & FCA Knowledge Base.

4. Live compliance health score

A single 0–100 score per firm, computed in real time:

  • 40% doc completeness (% of clients with all required document types complete)
  • 35% review completion (% of reviews in complete status)
  • 25% flag score (100 minus weighted penalty: critical=15, high=8, medium=3, low=1)

The score updates instantly when a document is uploaded or a flag is resolved.

5. AI-generated FCA-ready reports

Six report types (RMAR, Suitability, Consumer Duty, Activity Log, Vulnerable Clients, Board Summary). Each is generated by composing live firm data with FCA-corpus retrieval and an executive analysis section written by Claude grounded in retrieved regulatory text. Reports are snapshotted as JSONB at generation time so they don't change retroactively.

6. Nightly automated compliance monitoring

A Vercel cron job runs at 06:00 UTC every night. It evaluates every overdue annual review against COBS 9.5 using Claude (assessing whether the adviser's recorded delay reason constitutes a sufficient justification), creates or resolves risk flags accordingly, and writes to the compliance event audit trail. A second cron runs every Monday at 08:00 UTC to ingest new FCA Horizon publications into the knowledge base.

Strategic decisions baked into the MVP

These have been deliberately chosen, not defaults, and are worth knowing.

IFA-first GTM, not networks (May 2026). Network deals come with long procurement cycles and pricing constraints. Direct IFA relationships give faster feedback, pricing control, and real usage data before scaling. We will revisit network distribution once we have ~50 direct customers and clear product-market fit signals.

Read-only Intelliflo integration at MVP (May 2026). Write access creates liability (we could corrupt an IFA's CRM) and requires deeper security review. Read-only is sufficient to deliver core value at MVP and dramatically reduces the firm's risk surface.

Adviser-count tier pricing, not per-client (April 2026). Per-client pricing penalises growth and creates unpredictable costs. Flat per-firm-size SaaS pricing aligns Amaea's revenue with the firm's growth without friction.

UK-only launch, no international before 2030 (April 2026). Consumer Duty is UK-specific. International markets have entirely different compliance frameworks. Focus beats optionality at this stage.

Founders Programme as GTM entry (March 2026). 200 founder spots at 20% lifetime discount, accessed through four warm channels: FP Advance Conference, Robin Powell's newsletter, the CISI member network, and Intelliflo's firm base. These channels concentrate compliance-aware IFAs who are predisposed to be early adopters.

Bootstrap by default; raise only from strength (May 2026). With Hasna's GTM network and ~70% gross margins, the business should be self-funding from early scale. External capital is optional, not required. If raised, it'll be from strength (competitor entry / international expansion / acquisition opportunity) rather than need.

Pricing

Four tiers — Essentials, Professional, Scale, Enterprise — priced by adviser count, not per managed client. The Professional tier (~£1,599/mo) is the assumed default in the financial model. The full live pricing, tier feature splits, trial terms, and Founders Programme details are the canonical source of truth at amaea.co.uk/pricing — this doc deliberately does not reproduce them to avoid drift.

Founders Programme: 200 spots at 20% off for life, ref-based via FP Advance / Robin Powell / CISI / Intelliflo.

Roadmap

Phase 1 — Foundation (Q1–Q2 2026, in progress) Core compliance dashboard, client journey tracking, Intelliflo read integration, marketing website, 19-type document extraction pipeline (shipped May 2026), auto-flag-raising with FCA rule citations (shipped May 2026), AI compliance assistant (shipped May 2026 with dual RAG + 11,645-chunk FCA corpus), multi-page document grouping (shipped May 2026).

Phase 2 — Intelligence (Q3–Q4 2026, planned) Annual review auto-generation, Consumer Duty annual assessment report generation, vulnerable client enhanced monitoring, SharePoint integration, priority support and onboarding workflows.

Phase 3 — Scale (2027) Full integration suite (Salesforce + Dynamic Planner + Evidentli + others), board-level reporting packs, FCA visit preparation toolkit, custom report builder, multi-adviser firm management, Open API beta.

Phase 4 — Launch (Q1–Q3 2028) Public launch: September 2028. Enterprise / network tier, custom AI training on firm policies, dedicated compliance success manager offering, FCA mock audit module.
